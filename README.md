## 🚀 How to Run Locally

### 1. Backend Server
```bash
cd backend
npm install
npm run dev
```
Runs at: `http://localhost:5000`

### 2. Frontend App
```bash
cd frontend
npm install
npm run dev
```
Runs at: `http://localhost:5173`
